# TODOs 风格任务看板（Kanban Board）

## 概述与设计

本项改动将 Web 前端默认展示层从原先的“单表单提交流”升级为现代 **TODOs.dev 风格的多列看板流（Kanban Board）**。

### 1. 实体状态与五列看板映射

系统将 `tasks` 与关联的最新 `runs` 数据按状态机清晰映射到五列看板中：

1. **待办 (To Do)**：处于 `TODO` 状态或尚未开始运行的任务，支持一键创建 Run 或重新排期。
2. **执行中 (In Progress)**：最新 Run 处于 `PENDING`、`PROVISIONING`、`RUNNING` 或 `VERIFYING` 状态，实时展示当前执行阶段标签（`Stage: 规划 / 实现步骤 / 测试`）、节点和 Agent 类型，支持查看实时事件与取消。
3. **等待补充信息 (Blocked)**：最新 Run 处于 `NEEDS_INPUT` 状态，醒目高亮橙红色边框，展示 Agent 提出的问题简报，点击卡片直接打开回答对话框，无需在多页面间来回跳转。
4. **待交付验收 (Review)**：最新 Run 处于 `REVIEW` 状态，展示绿色通过徽标，点击卡片直接弹出包含 Diff、独立评审、验收标准验证与“验收通过/拒绝”操作的详情面板。
5. **已完成/归档 (Done)**：已顺利完成验收（`SUCCEEDED` / `DONE`）或终态归档（`FAILED` / `CANCELLED` / `REJECTED`）的任务，支持失败任务一键重新运行（Rerun）。

### 2. 交互体验提升

- **极简新建任务弹窗**：看板顶部提供常驻的 `+ 新建任务` 按钮，点击唤起弹窗输入目录、节点、Agent 和需求，提交后立即在看板“执行中”列生成卡片并开启详情抽屉。
- **上下文不丢失的详情弹窗**：在看板中点击任意卡片，弹出模态详情窗口（实时日志流、阶段进展、测试退出码、代码差异），关闭模态框后依然保持在看板视角。
- **保留经典列表视图**：顶部导航栏保留“新建/列表”、“执行流程”、“交付验收”与“配置”选项卡，兼顾看板操作与密集表格审计需求。
